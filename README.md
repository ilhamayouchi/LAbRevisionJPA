# TP JPA / Hibernate — hibernateSir

## Lancer
1. Démarrer Apache + MySQL (XAMPP / WAMP / Laragon).
2. Ouvrir http://localhost/phpmyadmin (la base `h1` est créée automatiquement, sinon la créer à la main).
3. Vérifier `src/main/resources/META-INF/persistence.xml` (utilisateur `root`, mot de passe vide par défaut).
4. Exécuter depuis l'IDE `org.example.test.TestCategorie` puis `org.example.test.TestGlobal`.
5. Rafraîchir phpMyAdmin (F5) : tables `categories, produits, users, clients, employes, services, employe_service, commande, ligne_commande_produit`.
